# 使用说明

[English](android-ui.md) · [返回 README](../README.zh-CN.md)

## 落子与分析

首次启动显示 AlphaGo 对李世石第四局（2016-03-13）的主线前 50 手，停在第 50 手。通过右上角三点菜单「清空棋盘」开始新局，沿用当前规则和贴目。
默认双方手动落子，点击合法交叉点即可落子；菜单中的「停一手」用于 pass。

右上角 KataGo 开关控制分析，关闭后保留已有结果。未分析局面不显示虚构胜率或推荐点。
走势与主胜率数值采用黑棋视角；候选点颜色采用当前行棋方视角。

开启 KataGo 后，打开保存的棋谱或导入 SGF，会先分析当前局面，再按设置的 visits 预算
逐一计算历史与变化节点。每完成一个局面，胜率曲线就会更新，分析区底部显示棋谱分析进度。
已有足够搜索次数的结果会复用缓存；关闭 KataGo 暂停，重新开启后继续补齐。
跳转时优先分析新选中的局面。自动落子、变化预览、设置／引擎页面及应用进入后台时暂停历史计算。
棋谱越长、每步 visits 越多，完成整谱分析所需时间越长。历史完成后持续加深当前局面，直到关闭 KataGo。
黑棋或白棋任一方自动落子时，隐藏棋盘候选落点与停一手建议，胜率继续计算；自动暂时暂停时同样隐藏。

A/B/C 保留引擎推荐顺序。颜色使用「最佳已评估合法候选胜率 − 该候选胜率」：
损失不超过 2 个百分点为绿，5 个百分点为黄，10 个百分点及以上为红，中间连续渐变。
因此开局约 50% 时，接近最佳的前三个点可以全部为绿色。未经搜索的交叉点不会仅根据坐标
被判成红色；例如 A1 是否糟糕，应以该局面的实际评估为准。

<img src="images/opening-en.png" width="360" alt="开局胜率约 50%，接近最佳的三个候选点均显示为绿色" />

点击候选点直接落子，长按预览其变化的前至多七手。预览不写入棋谱，点「退出预览」或系统返回即可退出。

## 跳转与变化

用首手、上一手、下一手、末手按钮，或直接点胜率图跳转。回看时保留完整选中分支，仍可前进。
未分析手数也能选择，走势只连接连续已分析局面。没有定时自动回放功能。

变化树支持点选节点、拖动、双指缩放和定位当前节点。在历史位置落子会新建变化。
回看、导入或重新打开棋谱会暂停自动落子。当前行棋方为自动时，「自动已暂停」提示下方
会直接显示「继续自动落子」，点击即可恢复，并在需要时开启 KataGo。
三点菜单中的「继续自动落子」也可恢复自动落子。

## 设置与引擎

设置页所有字段和开关先修改草稿，最后用底部「应用全部设置」一次保存。
任一数字无效时不能应用；新规则通过棋谱校验后才提交整份设置。离开设置前请先应用。

- 搜索预算：1–50,000 visits，默认 500，用于初始分析、历史局面和自动落子；手动分析会继续增加 visits。
- 自动落子：黑、白可分别启用；双方开启则自动对弈，仍受顶部 KataGo 开关控制。
- 规则与贴目：中国、韩国、日本，贴目 −400 至 400，允许小数，正数表示白棋贴目。
- 触控偏移：0–300 实际屏幕像素，提供 0/60/120 预设。拖动预览，松手落子；棋盘下方留有触控区域。
- 引擎与模型：即时切换 b6c96 / b10c128 和自动 / CPU / NPU；测速不改变棋局搜索预算。

横屏时控制区和分析区移到棋盘右侧，让棋盘使用更多可用高度。

<img src="images/landscape-en.png" width="800" alt="横屏棋盘与右侧分析控制区" />

自动模式尝试可用的 NPU 运行时，初始化失败则使用 CPU；手选 NPU 不会静默回退。
结果记录实际后端。visits/s 是搜索吞吐量，不等于网络推理次数，也不直接表示棋力。

## SGF 与语言

SGF 导入、导出和清空棋盘仅放在三点菜单，设置中不再重复。
使用系统文件选择器，支持 19 路棋谱、变化、注释、棋手信息、根节点摆子和 PL 行棋方。
不支持的棋谱会报告错误并保留原棋谱。导出包含全部变化，详情见 [SGF support](game-settings.md)。

在系统设置 → 应用 → KataDroid → 语言中切换中文和英文；默认跟随系统。
